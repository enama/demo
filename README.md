# Spring Boot Foundation

Personal repository for learning Spring Boot fundamentals.

## Structure

```text
concepts/       -> Theory and notes
labs/           -> Hands-on exercises
examples/       -> Useful code examples
product-service/ -> Spring Boot application
```

## Run the Application

```bash
cd product-service
./mvnw spring-boot:run
```

If using Windows:

```cmd
mvnw.cmd spring-boot:run
```

## Access the Application

Open the forwarded Codespaces URL or:

```text
http://localhost:8080
```

## Build

```bash
./mvnw package
```

## Run Tests

```bash
./mvnw test
```
